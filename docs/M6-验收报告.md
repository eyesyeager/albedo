## 5. 安全项

- SSRF：`127.0.0.1`、`169.254.169.254`、`10.0.0.8`、`localhost` 全部拦截。
- Skill 包：`../` 路径、符号链接、非法 manifest、非 ZIP、501 个文件均拒绝。
- 脱敏：`Bearer` token、`sk-*`、`apiKey`/`accessKey` 在日志与 CSV 导出中不出现明文。
- 签名下载：篡改 taskId、过期时间、空签名均校验失败。
- 并发保存：两个并发 PATCH 结果为一个 200、一个 409。

## 6. 性能与备份

- 压测（20 并发 × 5 轮 × 2 接口，共 200 请求）：错误 0，P50 306.6 ms，P95 562.4 ms，最大 599.5 ms（远程 MySQL 延迟为主）。
- 备份：`scripts/backup_db.py` 生成 20 表、约 126 KB 的 JSON 快照；`mysqldump` 因云账号缺少 `RELOAD` 权限不可用，已改为逻辑导出。

## 7. 未完成与限制

- Docker/gVisor 沙箱：本机无 Docker，`code_interpreter` 保持明确降级，未执行任何代码。
- `log_entries` 按月分区未实施（需要调整主键与迁移）；现有 `(run_id, timestamp)`、`(type, status, timestamp)` 索引可支撑当前规模。
- AGUI 已改为 `astream_events` 的 token 级增量；同 runId 完成后 10 分钟内可按 `Last-Event-ID` 回放，运行中跨进程订阅尚未实现。
- MCP live 默认关闭（seed 端点为演示地址），开启后连接失败自动降级。
- 签名 URL 仍保留会话鉴权作为兜底，未做独立的匿名下载网关。
