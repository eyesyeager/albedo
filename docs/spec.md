# Albedo 需求规格速览（SPEC）

> 本文是 `prd.md` V1.4 的简化视图，便于开发与测试快速对齐。
> 🔴 冲突时：产品语义以 `prd.md` 为准，技术实现以 `architecture.md` 为准，接口以 `api-spec.md` 为准。

---

## 1. 一句话定义

一个多租户 AI 文本问答底座：不同租户通过各自三级域名访问，拥有独立品牌配置、成员关系、Agent、能力资源与会话数据，共享同一套平台能力与同一个后端单体服务。

## 2. 角色

| 角色 | 认定来源 | 能做什么 |
|---|---|---|
| 匿名访客 | 无有效 Token | 看公开站点配置与 Agent 展示信息 |
| 终端用户 | 本地成员关系（惰性创建） | 用已发布 Agent，管理本人会话 |
| 租户运营 | 本地成员关系 | 管本租户文案与 AI 资源，看审计；不管成员角色 |
| 租户管理员 | 本地成员关系 | 管本租户全部资源、成员角色、Tool 授权、审计 |
| 平台管理员 | eyesUser `role=ADMIN` | 管租户/域名/本地 Tool 注册；跨租户访问需受控授权 |

## 3. 里程碑范围

| 里程碑 | 闭环 | 关键交付 |
|---|---|---|
| **M1** | 核心问答 | 租户识别、耶瞳 SSO、已发布站点配置读取、已发布 Agent 选择与运行、会话 CRUD、流式对话（停止/重试/重新生成/Markdown 安全） |
| **M2** | 管理治理 | 管理后台全量、配置与资源的草稿→校验→发布→回滚、RBAC、审计 |
| **M3** | 能力编排 | Skill 注入、MCP（`streamable_http`/`sse`）运行时、本地 Tool 编排与风险确认、埋点、历史建流前限流；用内置 Mock MCP 验收 |
| **用户限流与日限额（待交付）** | 资源治理 | tenantId+uid QPM、租户日历日 50 次默认限额、配置覆盖、计数结算、前端额度展示 |

## 4. 不做（明确非范围）

图片/文件/音频上传与知识库问答、语音输入输出、终端用户自建 Agent/Skill/MCP、额度购买/套餐/赠送/结转、用户级白名单或个人加额、租户自定义域名、跨租户会话共享、任意代码上传为 Tool。

## 5. 必须守住的硬规则

```
1. 租户身份只来源于可信 Host；请求参数中的 tenantId 一律忽略（记安全日志，不报错）
2. 所有租户业务数据/缓存/异步任务/日志都带租户维度；跨租户访问统一按"资源不存在"处理
3. 登录/注册/失效重登/退出全部由前端整页跳转耶瞳 SSO；后端无任何自建认证接口
4. Token 只存 localStorage、只走 Header authorization，回跳后立即从 URL 清除
5. auth-type=1：响应头出现新 token 必须立即回写，否则下次请求失败
6. /api/v1/** 一律 HTTP 200 + code（code=0 唯一成功，必带 timestamp）
   唯一例外：GET /site/status（未知 Host 404 / 暂停 403 / 配置异常 503）
7. 20000~20999 是耶瞳保留段，业务错误码严禁占用；禁止 10002 / 40001
8. 会话绑定创建时的 Agent 已发布版本，旧会话不静默切版
9. 配置与资源线上变更走「草稿 → 校验 → 发布」，发布版本不可变，失败保留上一版本
10. 消息发送幂等（Idempotency-Key）；重试不重复创建用户消息、不重复执行非幂等工具
11. 消息 1~20000 Unicode 字符，纯空白不可发送（前后端一致校验）
12. Markdown 安全渲染，禁脚本/事件属性/危险协议；代码块可复制不可执行
13. 反硬编码：平台参数入 sys_config，租户文案入 site_config_versions，静态 UI 文案入 locales
14. dev Host 映射生产必须关闭（开启则应用启动失败）
15. 时间存储 UTC，对外 ISO-8601；对外 id/uid 一律 string
16. QPM 与日限额按 tenantId+uid 独立：数据库平台默认 3 次/分钟、50 次/日，租户可覆盖，代码不得兜底硬编码
17. QPM 沿用 10005 + retryAfterSeconds；日限额用独立 30000 段业务码；历史小时窗废弃
18. 日额度按租户 IANA 时区当地零点重置；不用 UTC 零点或固定 24 小时滚动窗
19. 日额度按已开始消耗生成资源的尝试结算：生成前失败不计，开始后的完成/停止/断流/失败计；幂等重放不重复计
20. Composer 展示本人当前租户剩余、已用/总量、重置时间；用尽保留输入和草稿但禁用发送；匿名不展示
```

## 6. 关键状态机

```
租户：      draft → enabled ⇄ suspended → archived
配置/资源：  draft → published → archived
Agent：     enabled ⇄ disabled → deleted（有历史会话不可删，只能停用）
会话：      active ⇄ readOnly → deleted（软删 30 天后物理清除）
助手消息：  queued → streaming → completed | stopped | failed
工具调用：  pending → awaiting_confirmation → running → succeeded | failed | timed_out | cancelled | denied
租户成员：  active ⇄ disabled（disabled 不因再次访问自动恢复）
```

## 7. 核心指标

| 指标 | 目标 |
|---|---|
| 有效 Host 租户识别准确率 | 100% |
| 跨租户数据泄露 | 0 |
| 租户识别 + 配置读取 P95 | ≤ 20ms |
| 非 AI 接口 P95 / P99 | ≤ 500ms / ≤ 1s |
| AI 首字响应 P95 | ≤ 5s |
| 停止生成前端反馈 | ≤ 1s |
| 核心页面可交互 P95 | ≤ 2s |
| 配置发布生效成功率 | ≥ 99.9% |
| 应审计事件字段完整率 | 100% |
