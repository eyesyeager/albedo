# 运维信息

> 本文件不包含任何连接凭据。所有凭据通过环境变量或本机 `.env`（已被 `.gitignore` 忽略）注入，禁止写入仓库、日志与报告。

| MySQL | 8.0 | 业务数据与会话 | `DATABASE_URL` |

## 配置注入

在 `backend/` 下执行 `cp .env.example .env`，然后按实际环境填写（密码中的特殊字符需 URL 编码）：

- `DATABASE_URL`：形如 `mysql+aiomysql://USER:URL_ENCODED_PASSWORD@HOST:PORT/albedo`
- `REDIS_URL`：形如 `redis://:URL_ENCODED_PASSWORD@HOST:PORT/0`
- `SECRET_KEY`：使用 `Fernet.generate_key()` 生成，用于凭据加密与导出签名；**不可为空、不可轮换而不迁移已加密数据**
- `DEMO_ACCESS_KEY`：管理面初始访问 Key，必填且不得使用公开文档中的演示值
- `PLATFORM_DOMAIN`：对外发布地址，用于生成 API 示例代码
- `CORS_ORIGINS`：允许的前端来源，逗号分隔，生产环境禁止 `*`
- 模型与 MCP 始终走真实链路；业务枚举、默认值、限额与运行时参数存放在数据库 `system_configs` 表，通过 `GET/PATCH /api/v1/settings/configs` 调整，不在环境变量中配置
- `COOKIE_SECURE=true`、`CSRF_ENABLED=true`、`ENVIRONMENT=production`：生产环境强制项

`backend/app/core/config.py` 会在非 dev 环境启动时校验上述配置，缺失或仍使用演示值将直接拒绝启动。
