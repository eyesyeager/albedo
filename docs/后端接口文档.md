# albedo 后端接口文档

> 文档版本：v1.1
> 日期：2026-11-04
> 状态：设计基线，与 `docs/后端系统架构设计.md`、`docs/后端实施计划.md` 配套
> 服务端技术栈：**Python 3.12 · FastAPI · LangGraph（LangChain 生态）**
> 契约来源：Pydantic v2 模型经 FastAPI 自动生成 OpenAPI 3.1（`/openapi.json`）；字段与枚举对齐 `frontend/src/types/domain.ts`、`frontend/src/lib/api.ts`、`docs/智能体开发平台-产品文档.md`（第 3.1.3、3.5.4、7、10 章）

## 1. 通用约定

### 1.1 Base URL 与认证

| 平面 | Base URL | 认证方式 |
|---|---|---|
| 管理面 | `/api/v1` | `Cookie: albedo_session=<opaque>`（HttpOnly / Secure / SameSite=Lax，空闲 2h、绝对 24h）+ CSRF Token |
| 对外 · Agent | `/v1`、`/api/agui/v1` | `Authorization: Bearer <Agent Token>` |
| 对外 · 模型 | `/v1` | `Authorization: Bearer <发布版本自定义 Key>` |

前端展示的域名由 `GET /api/v1/workspace/bootstrap` 下发的 `settings.domain` 决定，保证发布页 Endpoint 与真实网关一致。

### 1.2 数据约定

- 请求与响应均为 `application/json`；Skill 上传与文件下载除外。
- 时间统一 ISO 8601 UTC 字符串，按 `settings.timezone` 渲染。
- 所有字段名、枚举值与 `frontend/src/types/domain.ts` 完全一致；ID 前缀见产品文档 10.1。
- 分页：`?page=1&pageSize=20`，返回 `{items, total, page, pageSize}`；筛选条件变化后前端重置 `page=1`。
- 列表筛选参数与 `LogFilters` 同名：`keyword` / `type` / `status` / `range` / `agentId`。
- 密钥字段：所有读接口仅返回 `credentialSuffix`；完整值只在创建 / 重置 / 轮换响应中出现一次。

### 1.3 统一成功与错误结构

成功：直接返回资源对象或集合包装（不套 `data` 壳），HTTP 状态 `200` / `201` / `202` / `204`。

错误（SSE 建立前）：

```json
{
  "error": {
    "code": "validation_error",
    "message": "System Prompt 保存前不可为空",
    "requestId": "req_01HXYZ"
  }
}
```

SSE 建立后：标准对话 API 发 `error` 事件，AGUI 发 `RUN_ERROR`，随后关闭连接；两者均带 `runId` 或 `requestId` 便于日志定位。

前端 `frontend/src/lib/http.ts` 把 `error.code` / `error.message` 转成 `ApiError(code, message)`，页面现有的 `toast.error(asError(reason).message)` 无需改动。

## 3. 核心接口详细定义

### 3.1 `GET /api/v1/workspace/bootstrap`

参数：无（Cookie 鉴权）。返回 `200`，结构与 `WorkspaceData` 完全同构：

```json
{
  "agents": [
    {
      "id": "agt-research",
      "name": "深度研究助手",
      "apiEnabled": true,
      "aguiEnabled": true,
      "credentialSuffix": "7K2m",
      "mounts": { "mcpIds": [], "skillIds": [], "toolIds": [], "modelIds": [] },
      "advanced": { "maxToolCalls": 12 }
    }
  ],
  "models": [],
  "publications": [],
  "mcps": [],
  "skills": [],
  "tools": [],
  "logs": [],
  "notifications": [],
  "exportTasks": [],
  "chatSessions": {},
  "trends": { "d14": [], "d30": [] },
  "settings": {
    "workspaceName": "于继钊的 AI 工作台",
    "domain": "https://api.albedo.local",
    "timezone": "Asia/Shanghai",
    "retentionDays": 90,
    "accessKeySuffix": "K9P4",
    "telemetry": true,
    "autoArchive": true,
    "language": "zh-CN"
  }
}
```

**安全约束**：`settings.accessKey` 明文绝不出现在响应中，仅返回 `accessKeySuffix`；`credentials` 表内容不出库。

错误：`401 invalid_api_key`（会话失效）、`403 agent_access_denied`。

### 3.2 `POST /api/v1/auth/login`

Body：

```json
{ "key": "albedo-demo-2026" }
```

服务端用 Argon2id 恒定时间比对，Redis 记失败次数（5 次锁 30 秒），成功 / 失败 / 限流均写 `type=system` 日志。

返回 `200`：

```json
{ "authenticated": true, "workspaceName": "于继钊的 AI 工作台" }
```

同时 `Set-Cookie: albedo_session=…; HttpOnly; Secure; SameSite=Lax`。

错误：`400 validation_error`（少于 12 字符）、`401 invalid_api_key`、`429 rate_limit_exceeded`。

### 3.3 `POST /api/v1/agents`

Body（`AgentDraft`，同 `frontend/src/types/domain.ts`）：

```json
{
  "name": "数据分析助手",
  "description": "面向业务指标的分析智能体",
  "defaultModelId": "mdl-gpt",
  "systemPrompt": "你是数据分析助手……"
}
```

服务端校验默认模型须 `enabled && type === 'chat' && connection === 'normal'`；分配 `agt-` ID、按现有数量循环主题色，填充默认值（温度 0.7 / Top P 0.9 / 最大输出 4096 / `maxToolCalls:10` / `maxRunSeconds:120` / 两协议关闭 / 会话数 0）。

返回 `201 Agent`（与 `agents.create` 返回类型一致）。

错误：`400 validation_error`、`404 resource_not_found`、`409 resource_in_use`。

### 3.4 `PATCH /api/v1/agents/:id`

Header：`If-Match: <version>`（乐观并发）。
Body：`Partial<Agent>`。

返回 `200`：

```json
{ "agent": {}, "version": 4, "updatedAt": "2026-11-04T12:00:00.000Z" }
```

适配层转成 `void` 以保持 `agents.update` 签名。

错误：`400 validation_error`（名称为空、Prompt 为空、参数越界）、`404 resource_not_found`、`409 stale_version`（提示刷新或比较）、`422 missing_variable`。

### 3.5 `PATCH /api/v1/agents/:id/protocols`

Body：

```json
{ "protocol": "api", "enabled": true }
```

开启时执行发布前检查：名称、Prompt、默认模型启用且连接正常、挂载资源未失效、`maxToolCalls` 1–100、`maxRunSeconds` 3–3600。失败返回 `409 publish_check_failed`：

```json
{
  "error": {
    "code": "publish_check_failed",
    "message": "发布前检查未通过：默认模型「GPT-4.1」连接状态异常，请重新测试连接",
    "requestId": "req_…",
    "issues": ["默认模型「GPT-4.1」连接状态异常，请重新测试连接"]
  }
}
```

两个开关独立；总体发布状态由 `apiEnabled || aguiEnabled` 派生；关闭其一不影响其二。

### 3.6 `POST /api/v1/agents/:id/credential/reset`

返回 `200`：

```json
{ "fullKey": "alb_agt_…", "credentialSuffix": "7K2m" }
```

旧 Token 在 Redis 与 DB 立即失效，写系统操作日志。适配层仅向前端返回 `fullKey` 字符串（保持 `resetCredential` 签名）；此后所有读接口只返回后缀。

### 3.7 `POST /api/v1/models/test`

Body：`ModelDraft`（含明文 `apiKey`）。服务端按类型执行最小请求：Chat 最短对话 / Embedding 固定短文本 / Rerank 固定查询与文档列表 / 多模态最小文本或图片请求；带 SSRF 防护（阻断元数据地址、回环、未授权内网）。

返回 `200`：

```json
{
  "latencyMs": 782,
  "httpStatus": 200,
  "errorCategory": null,
  "responseSummary": "chat.completion 返回结构合法"
}
```

错误：`400 validation_error`、`401 upstream_auth_failed`、`502 upstream_unavailable`、`504 upstream_timeout`。**不落库、不保存 Key、不产生重复资源**。

### 3.8 `POST /api/v1/models/:id/publications`

Body（`PublicationDraft`，同 `frontend/src/types/domain.ts`）：

```json
{
  "version": "v1.0.0",
  "callIdentifier": "albedo-gpt-4.1",
  "apiKey": "alb_sk_live_xxx",
  "headers": "{\"X-Env\":\"prod\"}",
  "temperature": 0.7,
  "maxOutputTokens": 4096,
  "qpm": 60
}
```

校验：版本号同模型内唯一；`callIdentifier` 全局唯一（含停用版本）且字符集 `[A-Za-z0-9._-]`；Key ≥ 12 字符（生产建议 ≥ 24 高熵字符）；Header 必须是合法 JSON 对象；温度 0–2；Tokens / QPM 为正整数；模型须 `enabled && connection === 'normal'` 且类型为 Chat / Embedding。

返回 `201`：

```json
{
  "publication": {
    "id": "pub-…",
    "modelId": "mdl-gpt",
    "version": "v1.0.0",
    "callIdentifier": "albedo-gpt-4.1",
    "credentialSuffix": "cure",
    "headersConfigured": true,
    "temperature": 0.7,
    "maxOutputTokens": 4096,
    "qpm": 60,
    "enabled": true,
    "createdAt": "2026-11-04T12:00:00.000Z"
  },
  "fullKey": "alb_sk_live_xxx"
}
```

错误：`400 validation_error`、`409 duplicate_identifier`（「该版本号已存在，请使用新的版本号」/「模型调用标识已被占用，请更换」）、`400 validation_error`（「自定义请求头必须是合法的 JSON 对象」）、`409 connection_test_required`。

### 3.8.1 `DELETE /api/v1/publications/:id`

删除指定发布版本：先删除其 `model_publication_key` 凭证，再删除版本行，返回 `WriteResponse`（`entity: null` + 审计日志）。删除后该版本 Key 立即失效（对外调用返回 `401 invalid_api_key`），调用标识与版本号被释放，可用于重新发布；同模型其他版本与模型资源不受影响。不存在时返回 `404 not_found`。

### 3.9 `POST /api/v1/skills` 与 `POST /api/v1/skills/:id/versions`

`multipart/form-data`：`name`（text）、`instructions`（text）、`file`（真实 zip 二进制）。

服务端校验：扩展名 `.zip`、≤100 MB、解压后总体积 / 文件数 / 目录深度限制、绝对路径与 `../` 穿越、危险符号链接、manifest 完整性与版本唯一性；包存入受限目录，脚本仅沙箱运行。新版本按 SemVer 递增，历史 `versions[]` 保留，已有 Agent 不自动升级。

返回 `201 Skill`（字段与 `frontend/src/types/domain.ts` 一致）。

错误：`400 validation_error`、`409 duplicate_identifier`、`413 payload_too_large`、`422 skill_manifest_invalid`。

### 3.10 `GET /api/v1/logs`

Query：`page`、`pageSize`、`keyword`、`type`、`status`、`range`、`agentId`。

服务端按真实时间戳倒序；`keyword` 覆盖对象名称、摘要、`runId`、`threadId`、`agentId` 与 **Agent 展示名称**（修正前端当前用 ID 代替名称的偏差）。

返回 `200`：

```json
{
  "items": [],
  "total": 128,
  "page": 1,
  "pageSize": 20,
  "typeCounts": { "session": 42, "mcp": 31, "skill": 8, "tool": 22, "model": 20, "system": 5 }
}
```

`GET /api/v1/logs/:logId` 额外返回 `chain: LogEntry[]`（同 `runId` 按 `timestamp` 升序），供执行链路时间线渲染；父 Run 与子调用状态独立，Run 超时后未完成子调用标记取消或超时。

### 3.11 `POST /api/v1/logs/exports`

Body（**注意**：前端现传整个 `filtered` 数组，需改为传筛选条件对象）：

```json
{
  "format": "csv",
  "filters": { "type": "all", "status": "failed", "range": "7d", "keyword": "", "agentId": "all" }
}
```

返回 `202 ExportTask`：

```json
{
  "id": "exp-wfrb2t",
  "createdAt": "2026-11-04T14:04:24.082Z",
  "format": "csv",
  "filters": "类型=全部 · 状态=失败 · 时间=7d",
  "recordCount": 18,
  "fileSizeBytes": 3416,
  "expiresAt": "2026-11-11T14:04:24.082Z",
  "status": "pending"
}
```

`GET /api/v1/logs/exports/:taskId` 轮询状态，`GET /api/v1/logs/exports/:taskId/download` 返回签名短时 URL。CSV 输出摘要字段、JSON 输出完整结构化字段，两者均执行与页面一致的脱敏，并记录导出审计日志。

### 3.12 `POST /api/v1/agents/:id/test-runs`

Body：

```json
{ "content": "请分析订单下降的原因", "testModelId": "mdl-deepseek", "threadId": "thd_test01" }
```

测试模型与默认模型分离。M5a 返回 `200 SendResult`，与 `frontend/src/types/domain.ts` 的 `SendResult` 结构完全一致：

```json
{
  "messages": [
    { "id": "msg-…", "role": "user", "content": "请分析订单下降的原因", "timestamp": "…" },
    { "id": "msg-…", "role": "tool", "content": "", "timestamp": "…", "toolCall": { "name": "Tavily Search / search", "args": "{\"query\":\"…\"}", "status": "success", "result": "已返回 5 条结果摘要" } },
    { "id": "msg-…", "role": "assistant", "content": "…", "timestamp": "…" }
  ],
  "runId": "run_8fk2m1",
  "threadId": "thd_test01"
}
```

服务端同时写 `session` / `model` / `mcp` / `tool` / `skill` 日志并 `sessionCount + 1`。M5b 在 `Accept: text/event-stream` 下改为 SSE 增量事件。

### 3.13 `POST /v1/agents/:agentId/chat`（对外）

Header：`Authorization: Bearer <Agent Token>`、`Content-Type: application/json`、`Accept: application/json`（流式时为 `text/event-stream`）。

Body：

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `messages` | array | 是 | — | 至少一条，每项 `role` / `content` |
| `threadId` | string | 否 | 服务端生成 | 复用可延续上下文 |
| `runId` | string | 否 | 服务端生成 | 调用方提供时须工作区唯一 |
| `variables` | object | 视配置 | `{}` | Prompt 自定义变量 |
| `stream` | boolean | 否 | `false` | SSE 流式返回 |
| `includeUsage` | boolean | 否 | `true` | 是否返回 Token 用量 |
| `metadata` | object | 否 | `{}` | 仅用于日志检索，不注入 Prompt |

非流式返回 `200`：

```json
{
  "id": "chatcmpl_8fk2m1",
  "object": "agent.chat.completion",
  "created": 1793174123,
  "agentId": "agt-research",
  "threadId": "thd_order_20261028_001",
  "runId": "run_8fk2m1",
  "status": "completed",
  "message": { "id": "msg_a_01", "role": "assistant", "content": "建议先确认流量、转化率和客单价……" },
  "usage": { "inputTokens": 1260, "outputTokens": 842, "totalTokens": 2102 },
  "finishReason": "stop",
  "metadata": { "durationMs": 3840, "toolCallCount": 2 }
}
```

`stream=true` 时返回 `message.start` / `message.delta` / `message.end` / `error` 事件；工具调用默认服务端内部执行，只返回最终回复与调用次数。

错误：`400 invalid_request`、`401 invalid_api_key`、`403 agent_access_denied`、`404 agent_not_found`、`409 agent_not_published` / `duplicate_run_id`、`422 missing_variable`、`429 rate_limit_exceeded`、`500 agent_run_failed`、`504 agent_run_timeout`。

### 3.14 `POST /api/agui/v1/agents/:agentId/run`（对外）

Header：`Authorization: Bearer <Agent Token>`、`Content-Type: application/json`、`Accept: text/event-stream`、`X-AGUI-Version: 1`。

Body（`RunAgentInput`）：`threadId`、`runId` 必填；`messages[]`（每项 `id` / `role` / `content`）、`tools?`、`context.variables?`、`state?`、`forwardedProps?`。前端声明的 `tools` 与平台已授权能力隔离校验。

**始终 SSE**，每条 `data` 至少含 `type` / `threadId` / `runId` / `timestamp` / `sequence`：

```text
event: RUN_STARTED
data: {"type":"RUN_STARTED","threadId":"thd_research_001","runId":"run_research_008","sequence":1,"timestamp":"2026-10-28T09:10:00.000Z"}

event: STATE_DELTA
data: {"type":"STATE_DELTA","sequence":2,"delta":[{"op":"replace","path":"/progress","value":10}]}

event: TOOL_CALL_START
data: {"type":"TOOL_CALL_START","sequence":3,"toolCallId":"call_01","toolCallName":"tavily_search"}

event: TOOL_CALL_ARGS
data: {"type":"TOOL_CALL_ARGS","sequence":4,"toolCallId":"call_01","args":{"query":"2026 新能源汽车市场趋势"}}

event: TOOL_CALL_END
data: {"type":"TOOL_CALL_END","sequence":5,"toolCallId":"call_01"}

event: TOOL_CALL_RESULT
data: {"type":"TOOL_CALL_RESULT","sequence":6,"toolCallId":"call_01","status":"success","content":{"resultCount":8}}

event: TEXT_MESSAGE_START
data: {"type":"TEXT_MESSAGE_START","sequence":7,"messageId":"msg_a_008","role":"assistant"}

event: TEXT_MESSAGE_CONTENT
data: {"type":"TEXT_MESSAGE_CONTENT","sequence":8,"messageId":"msg_a_008","delta":"2026 年新能源汽车市场将呈现以下趋势："}

event: TEXT_MESSAGE_END
data: {"type":"TEXT_MESSAGE_END","sequence":9,"messageId":"msg_a_008"}

event: RUN_FINISHED
data: {"type":"RUN_FINISHED","sequence":10,"status":"completed","usage":{"inputTokens":1820,"outputTokens":1360,"totalTokens":3180},"durationMs":8420}
```

事件顺序要求：`RUN_STARTED` 必须首个；文本 `START → CONTENT(0~N) → END` 配对；工具 `START → ARGS(1~N) → END → RESULT`；`RUN_FINISHED` / `RUN_ERROR` 为唯一终止事件；客户端按 `sequence` 去重排序，支持 `Last-Event-ID` 续传。SSE 建立后的错误用 `RUN_ERROR {code, message, retryable}` 关闭连接。

### 3.15 模型对外接口

| 接口 | 请求要点 | 响应要点 |
|---|---|---|
| `POST /v1/chat/completions` | `model` 填 `callIdentifier`，支持 `stream` / `temperature` / `max_tokens` | OpenAI 兼容结构，流式按分片透传 |
| `POST /v1/embeddings` | `model` + `input` | OpenAI 兼容向量结构 |
| `GET /v1/models` | 无 | 仅列当前 Key 有权调用且已发布启用的标识 |

调用方把 `base_url` 设为 `settings.domain + /v1`、`api_key` 设为目标版本自定义 Key。错误：`400 invalid_request`、`401 invalid_api_key`、`403 model_not_allowed`、`404 model_not_found`、`409 model_version_disabled`、`429 rate_limit_exceeded`、`502 upstream_error`、`504 upstream_timeout`。

## 4. 错误码体系

### 4.1 管理面（与前端 `ApiError` 现有 code 对齐）

| code | HTTP | 含义 | 前端归属 |
|---|---|---|---|
| `validation_error` | 400 | 字段校验失败 | 已有 |
| `invalid_api_key` | 401 | 会话 / 访问 Key 无效或失效 | 已有 |
| `rate_limit_exceeded` | 429 | 登录限流、MCP 额度、QPM 超限 | 已有 |
| `resource_not_found` | 404 | 资源不存在 | 已有 |
| `resource_disabled` | 409 | 资源已停用 | 已有 |
| `duplicate_identifier` | 409 | 版本号、调用标识、Tool Key 冲突 | 已有 |
| `connection_test_required` | 409 | 未通过连接测试，禁止发布 / 选用 | 已有 |
| `upstream_auth_failed` | 401 | 上游鉴权失败 | 已有 |
| `upstream_unavailable` | 502 | 上游不可达 | 已有 |
| `upstream_timeout` | 504 | 上游超时 | 已有 |
| `resource_in_use` | 409 | 被 Agent / 版本引用，禁止删除 | 新增（产品文档 10.3） |

| `stale_version` | 409 | 乐观并发冲突，提示刷新或比较 | 新增 |

| code | HTTP | 场景 |
